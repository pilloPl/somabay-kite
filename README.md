# Soma Bay — makieta gry

Makieta 3D (three.js, kamera ortograficzna jak w grach 2D) stacji kite/windsurf Surfmotion w Soma Bay (Egipt):
układ z pomiarów satelity, pływy, wiatr z fizyką leżących kitów, ekipa stacji.
